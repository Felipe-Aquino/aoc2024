# aoc2024
Solutions for Advent of Code 2024

Written in Clojure.

# Steps
```bash
$ clojure -M -m day01

======================================================================
Advent of Code Helper
======================================================================
Options:
  part=2         Runs part 1 (Required)
  input=example  Accepts one of 3 values: given, example, <path> (Required)

Usage examples:
  clojure -M -m day01 part=2 input=given
  clojure -M -m day01 part=1 input=./inputs/test.txt
======================================================================
```
